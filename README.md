# 🤖 BuddyBot — Your Friendly Python Companion

**A simple, interactive, and beginner-friendly rule-based chatbot built using Python.**

BuddyBot is a console-based chatbot developed as part of my Python programming internship at CodeAlpha. It interacts with users, provides predefined responses, suggests beginner-friendly project ideas, shares motivational quotes, and makes conversations more engaging.

The project demonstrates how basic Python concepts can be combined to create a useful and interactive application.

---

## ✨ Features

- 👋 **Personalized Greetings:** Greets users by their name.
- 💬 **Interactive Conversations:** Responds to predefined messages and questions.
- 🧠 **AI Project Suggestions:** Shares beginner-friendly ideas for AI-related projects.
- 💻 **Python Guidance:** Provides basic suggestions for learning Python and coding.
- 📚 **Study Assistance:** Offers simple study tips and exam preparation advice.
- 😂 **Random Jokes:** Shares programming jokes to make conversations fun.
- 🌟 **Motivational Quotes:** Provides randomly selected inspirational quotes.
- 🕒 **Current Time:** Displays the system's current time.
- 📖 **Help Menu:** Lists supported topics and commands.
- 👋 **Exit Command:** Ends the conversation gracefully.

---

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Modules:** `random`, `datetime`
- **Development Environment:** Visual Studio Code
- **Interface:** Command-Line Interface (CLI)

## ⚙️ Installation and Setup

Follow these steps to run BuddyBot on your computer.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project Folder

```bash
cd CodeAlpha_BasicChatbot
```

Use the folder name that matches your actual repository.

### 3. Check Python Installation

Make sure Python 3 is installed:

```bash
python --version
```

On Windows, you can also try:

```bash
py --version
```

### 4. Run the Chatbot

Execute the following command:

```bash
python chatbot.py
```

On Windows, if necessary, use:

```bash
py chatbot.py
```

BuddyBot will start in your terminal, and you can begin chatting!
